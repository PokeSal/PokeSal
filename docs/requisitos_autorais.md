# Requisitos Autorais - Projeto PokeSal

## Requisito Autoral 01 — Acerto Crítico Elemental
- **Mecânica:** 10% de chance base de Dano Crítico (1.5x). Sobe para 25% se o ataque tiver vantagem elemental.

## Requisito Autoral 02 — Habilidade Passiva "Determinação UCSal"
- **Mecânica:** Ao atingir HP < 20% do máximo pela primeira vez, o Pokésal ganha +20% no atributo DEF.

## Requisito Autoral 03 — Cansaço Extremo / Dano de Recuo
- **Mecânica:** A cada 3 turnos completos, o Pokésal que atacou sofre 5% de dano de recuo em seu HP máximo.
